# Batbox Homebrew tap

Install [Batbox](https://github.com/Digital-Disconnections-LTD/batbox), the terminal coding agent, with `brew install digital-disconnections-ltd/batbox/batbox`, or tap first with `brew tap digital-disconnections-ltd/batbox && brew trust --formula digital-disconnections-ltd/batbox/batbox && brew install batbox` (Homebrew 6 and later only load formulae from a non-official tap once you trust them; installing by the full name trusts this one formula for you). Add `--HEAD` to build the latest `main`. `Formula/batbox.rb` mirrors `packaging/homebrew/Formula/batbox.rb` in the Batbox repository. Bottles are built by the `brew test-bot` workflow on each pull request and published with the `brew pr-pull` workflow; because this repository is public, those GitHub Actions runs on macOS and Linux cost nothing. See the Batbox repository's `RELEASING.md` for the release steps.
